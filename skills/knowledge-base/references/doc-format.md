# 知识库文档格式模板

## 新问题条目模板

```markdown
---

## 问题标题（简短、可检索）

**日期：** YYYY-MM-DD
**场景：** 在什么操作系统/conda版本/操作下遇到
**现象：** 具体报错消息或异常行为描述
**截图：** ![报错截图](../screenshots/xxx.png)（如有）
**原因：** 根因分析
**解决：**

1. 步骤一
   ```bash
   command here
   ```
2. 步骤二
   ```bash
   command here
   ```

**验证：** 如何确认问题已解决
**参考：** 相关链接或其他文档引用
```

## 新命令条目模板

```markdown
### 命令名称

**用途：** 一句话说明
**语法：** `conda <command> [options]`
**常用选项：**
| 选项 | 说明 |
|------|------|
| `--name` | 环境名称 |
| `--file` | 从文件读取 |

**示例：**
```bash
conda <command> --name myenv
```
```

## 规则

- 每个条目用 `---` 分隔
- 标题层级：文档标题 `#`，大类 `##`，具体条目 `###`
- 截图路径使用相对于文档所在目录的相对路径
- 命令始终使用 bash 代码块（` ```bash `）
- 日期使用 ISO 格式 YYYY-MM-DD
