# 扩展路由规则

## 关键词匹配方法

### 精确匹配
用户问题中的关键词直接命中 `index.md` 索引表中的条目，直接路由到对应文档。

### 模糊匹配
当用户问题不是标准术语时，按以下规则展开：

| 用户说法 | 匹配方向 |
|---------|---------|
| "装个 conda" | installation.md |
| "conda 好慢" | channel-config.md（镜像源）或 package-ops.md（包下载慢） |
| "切换 python 版本" | env-management.md（创建新环境指定版本） |
| "conda 报了个错" | troubleshooting.md（需要截图或错误消息才能精确匹配） |
| "怎么把环境给别人" | env-management.md（环境导出/导入） |
| "conda 和 pip 区别" | 模型通用知识（非知识库范畴） |

### 多目标匹配
一个问题可能涉及多个文档，按以下优先级加载：
1. 先加载最直接相关的文档
2. 如果涉及操作步骤依赖其他知识域，追加加载
3. 最多同时加载 3 篇文档（超过则让用户缩小问题范围）

## 索引维护

当新增文档或在现有文档中添加内容时，同步更新 `index.md`：
- 新增问题类别 → 添加关键词行
- 新增常用命令 → 追加到命令速查区
- 新增截图 → 在对应文档中引用，不需要更新 index.md
